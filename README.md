## 🚀 Setup

Clone the repository:

```bash
git clone <repository-url>
cd agentic-ai-learning
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Install/select the Jupyter kernel if required:

```bash
python -m ipykernel install --user --name=agentic-ai
```

## 🔑 API Configuration

Create a `.env` file in the repository root:

```env
GEMINI_API_KEY=your_api_key_here
```

The `.env` file is excluded from Git using `.gitignore`.

Do **not** commit or share API keys publicly.

## 📓 Running the Notebooks

Open the repository in VS Code and select the `agentic-ai` Python kernel for the notebooks.

The primary implementation files are Jupyter notebooks (`.ipynb`) so that explanations, code, outputs, experiments, and visualizations remain together.
